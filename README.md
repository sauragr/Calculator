# Calculator

A simple browser-based calculator built with HTML, CSS, and JavaScript.

This project creates a basic calculator UI where users can perform arithmetic operations like addition, subtraction, multiplication, and division using a clean, interactive interface.

## Features

- Arithmetic operations:
  - Addition
  - Subtraction
  - Multiplication
  - Division
- Clear button to reset the calculator
- Equals button to evaluate the expression
- Responsive and simple layout
- No external dependencies required

## Tech Stack

- HTML
- CSS
- JavaScript

## Project Structure

```text
Calculator/
├── index.html
├── style.css
├── script.js
└── README.md
```

## How to Run

1. Clone the repository:
   ```bash
   git clone https://github.com/sauragr/Calculator.git
   ```

2. Open `index.html` in your browser.

3. Use the calculator to perform operations.

## Usage

- Click number buttons to enter values.
- Select an operator (`+`, `-`, `*`, `/`).
- Press `=` to calculate the result.
- Press `AC` to clear the current calculation.

## Example

```text
Input: 12 + 8
Output: 20
```
